# 📦 极速找快递 (Courier Pick)

一款基于 Android + Jetpack Compose 的快递单号快速识别应用。通过相机实时扫描或静态图片识别，**锁定目标快递单号**，同时支持 AI 人像/人头计数与多种识别算法切换。

> 本人使用，欢迎下载体验 · 最新 APK (v1.0.1) 见 [Releases](../../releases)

---

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 🔍 三种识别算法 | 快递找件 / 人头计数 / 条码聚焦，一键切换 |
| 🚚 快递单号锁定 | 输入单号后，命中条码以红框高亮并震动反馈 |
| 👥 人像/人头计数 | YOLO 神经网络识别画面中人像并实时统计人数 |
| ⚡ 实时性能仪表 | 实时显示 FPS 与单帧处理延迟 |
| 🖼️ 静态识别 + 分步反馈 | 选择图片识别，下方实时展示读取/解析/AI/匹配等处理步骤与耗时 |
| 📋 批量单号匹配 | 支持逗号/空格分隔多个单号同时匹配 |
| ⭐ 收藏夹 | 常用单号收藏，一键快速填充 |
| 🕐 识别历史 | 自动记录识别历史，支持删除与清空 |
| ✅ 命中反馈 | 命中目标时震动 + 绿色成功横幅动效 |
| 📤 结果分享 | 一键分享识别结果摘要 |

---

## 📱 应用界面

- **实时识别**：相机预览 + 红框命中高亮 + 性能仪表 + 人数徽标
- **静态识别**：图片叠加识别框 + 分步处理反馈日志面板
- **三种算法**：快递找件（条码+对象）、人头计数（人像统计）、条码聚焦（最快）

---

## 🛠️ 技术栈

- **语言**：Kotlin 2.0 · **UI**：Jetpack Compose (Material 3)
- **相机**：CameraX (Preview + ImageAnalysis)
- **AI 识别**：ONNX Runtime (YOLO) 端侧推理
- **条码解码**：ZXing (支持多种一维码 / 二维码)
- **持久化**：SharedPreferences（历史记录 / 收藏夹）

---

## 🚀 构建

```bash
# 需要 Android SDK + JDK 17
./gradlew assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`
